# Ruta Applied AI Engineer — 8 meses

Aplicación web estática, responsive e instalable para dar seguimiento a una ruta personal de formación en Applied AI Engineering.

## Publicar gratis con GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube **todos los archivos y carpetas de este proyecto** al repositorio.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main`, carpeta `/ (root)` y guarda.
6. GitHub mostrará la dirección pública. Ábrela desde el teléfono y usa **Añadir a pantalla de inicio**.

## Desarrollo local

No requiere instalación ni compilación. Abre `dist/index.html` o sirve la carpeta `dist` con cualquier servidor web estático.

## Datos y privacidad

El progreso y la bitácora se guardan únicamente en `localStorage` del navegador. No se envían a ningún servidor. Si borras los datos del navegador o cambias de teléfono, el progreso no se sincronizará.
